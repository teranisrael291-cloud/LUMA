# LUMA Creators — Vercel static site

Sitio estático HTML/CSS/JS listo para desplegar en Vercel.

## Deploy
1. Sube la carpeta a GitHub o arrástrala a Vercel.
2. Framework Preset: `Other`.
3. Build Command: vacío.
4. Output Directory: vacío.

## Notas
- Los perfiles de creators, métricas y señales de LUMA Pulse son ficticios y están marcados como demo.
- Las tres estadísticas de mercado enlazan a sus fuentes en el footer.
- Las imágenes de creators usan Unsplash y requieren conexión a internet.
- El logotipo `assets/luma-mark.svg` sigue la guía visual compartida: Charcoal #1A1A1A + Luma Orange #FF7A3D.
