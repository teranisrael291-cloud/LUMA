# LUMA V8 — product and editorial changes

## Pulse

Pulse now separates three questions that were previously mixed together:

- **How fast is it moving?** Momentum.
- **How much should we trust the signal?** Confidence.
- **What kind of phenomenon is it?** Cultural moment, emerging trend or structural shift.

The new Signal Map makes the first two dimensions visible at once. Cultural Horizon prevents short viral spikes from being presented with the same weight as persistent consumer shifts. Signal Anatomy exposes the main ML/NLP components behind each score.

## ML/NLP

The engine now uses hybrid similarity instead of a single cosine threshold, adds source agreement, temporal burst, novelty, persistence, whitespace and velocity, and uses prior published editions as a lightweight historical memory. Candidate selection uses diversity-aware ranking so one category or publisher is less likely to dominate the edition.

## Sources

The curated catalog expands to 45 sources and explicitly separates platform signals, market evidence, foresight, marketing trade press and cultural/editorial sources. This is intended to improve triangulation rather than simply increase volume.

## Visual language

Emoji glyphs were removed from the public site and editor. Navigation marks, signal marks, arrows, close controls and decorative symbols are now CSS/SVG geometry aligned to the LUMA visual system.
